## Compatibility correction

`phpDocumentor\Reflection\DocBlock` is mutable through `removeTag()`. Returning
the cached object allowed one caller to remove tags from subsequent results.
The new regression failed on the saved branch. The factory now caches a
template and returns a clone on both misses and hits, preserving the parsing
savings while isolating each result's tag list.

Additional regressions cover differing import aliases in the same namespace
and explicit source locations. Existing same-second file edit coverage remains.

## PR follow-up

After integrating current master and addressing scanner feedback, the full
installed-runtime suite passed with coverage: 174 tests, 7,636 assertions,
3 skipped. `MemoizingDocBlockFactory`, `AstPreparationVisitor`, and the legacy
`ParentConnector` each have all statements covered. A compatibility regression

legacy visitor pipeline across grouped imports, nested declarations, multiple

turnover. Internal array identifiers now use SHA-256 instead of MD5; no security
